# 2026 诺贝尔化学奖：分子的左右手

4 分钟，1920×1080，60fps，无旁白（字幕 + 配乐），响度 −14 LUFS。

讲 2026 年诺贝尔化学奖：亨利·B·卡甘（Henri B. Kagan）与硖合宪三（Kenso Soai），“表彰他们发现不对称有机合成中的非线性效应和自催化现象”。

## 目录

| 路径 | 内容 |
|---|---|
| `chem2026.mp4` | 成片（不进 git，用 `build.sh` 复刻） |
| `src/` | Remotion 源码：`Film.tsx` 总装，`cues.json` 场景时间表（画面和配乐共用，含 BPM），`scenes/` 各场景，`ui.tsx` 纸张/网格/出字/风车符号/章节卡等组件，`anim.ts` 缓动与动画工具，`theme.ts` 配色与网格模数 |
| `audio/chem2026_audio.py` | 配乐与音效合成（numpy/scipy，固定随机种子；合成器函数沿用 `films/nobel2026`） |
| `audio/master.sh` | 两遍 ffmpeg loudnorm 母带处理 |
| `assets/audio.wav` | 母带后的配乐，渲染时直接引用（不进 git，`build.sh` 缺失时自动生成） |
| `build.sh` | 一键复现，产物写入 `build/` |

工作区根目录的 `src/Root.tsx` 注册合成 `Chem2026`。

## 复现

```bash
pnpm install --frozen-lockfile        # 在工作区根目录，node_modules 缺失时
films/chem2026/build.sh               # 配乐 + 渲染；也可只跑 audio 或 video
```

成片出现在 `films/chem2026/build/chem2026.mp4`。已有的 `assets/audio.wav` 和成片不会被覆盖。

配乐基准：`assets/audio.wav` 的 PCM MD5 应为 `1ebdda95c8a1e6f9f938cc7b4d1cfd01`（`build.sh audio` 会打印）。Python 包版本不同时可能不再逐字节一致，但听感相同。

## 风格选择

用户只给了主题、时长（3–5 分钟）和规格（1080p60）。沿用上一部片子“无旁白，字幕 + 配乐”的做法。风格由 agent 按根目录 `AGENTS.md` 的流程自选：

| 段落 | 风格 | 理由 |
|---|---|---|
| 全片主体 | [`09-bauhaus`](https://github.com/Vincentwei1021/mg-styles-15/blob/main/prompts/09-bauhaus.md) 包豪斯动态海报（米色纸、红黄蓝黑限定色、120px 严格网格、无过冲的机械缓动、120 BPM 节拍驱动、章节卡逐列落下） | 主题就是“镜像对称”：中轴线、左右对称的构图天然对应；红 = 左手型、蓝 = 右手型、黄 = 金属催化剂 / 诺奖，三原色正好够用 |
| 嘧啶环、反应式、非线性曲线、烧瓶、晶体轮廓 | [`02-line-art`](https://github.com/Vincentwei1021/mg-styles-15/blob/main/prompts/02-line-art.md) 线描（描边生长、转角减速） | 化学结构式本来就是线画的，描线生长适合“写出”分子和曲线 |
| 01 章丙氨酸 | 自创：三维球棍模型（按 L-丙氨酸 S 构型真实排布，镜像得到 D 型），柔光、红蓝底座 | 提示词里没有对应风格，但“怎么转都叠不上”只有三维才看得明白 |
| 手性符号 | 自创：三叶风车。二维里也有手性，顺时针 / 逆时针两种，贯穿全片代表左右手型分子 | 让观众不用读结构式也能分清左右 |

风格提示词来自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)（作者 Vincentwei1021，MIT 许可）。本片只参考了风格描述，画面代码是重新编写的，没有复制该仓库的源码或素材。

排除的风格：回形针（上一部已用，且本题的视觉核心是对称而非信息拼贴）、合成波 / 液态 / 像素等偏装饰，不适合科普叙事。配乐按包豪斯提示词的建议做成极简电子（每个几何动作配一个带音高的咔嗒声，底鼓走四分音符）。
